# 课程项目说明

心晴是《高级语言编程实训2》的 Qt/C++ 桌面应用项目。仓库以界面和交互实现为主，模型调用与 A22 推理工具用于支撑情绪陪伴场景。

程序入口在 `app/main.cpp`。`MainWindow` 创建聊天区、会话列表和配置窗口，通过 Qt 信号与槽响应发送、切换会话等操作。`QNetworkAccessManager` 以异步请求调用模型接口，`onChatReadyRead` 接收 SSE 流式数据，定时器把增量文本更新到界面，避免频繁重排。

`ChatSession` 管理独立会话，`ChatMessage` 保存消息角色、正文、服务返回的思考文本及情绪。会话序列化为本地 JSON，在启动时恢复。`AmbientCanvas` 绘制背景，`QVariantAnimation` 控制情绪变化时的颜色过渡；`ZenMiniBar` 提供伴读浮窗。`ResultLoader` 保留结构化结果文件的读取能力。

界面使用模型返回的 `response_text` 展示回复，使用 `emotion_label` 改变背景。普通文本回复也可以显示，但不会产生可靠的情绪标签。标签来自模型判断，并非医学诊断。

展示顺序：先介绍 Qt 界面与交互，再演示 API 配置、流式聊天、多会话保存和伴读浮窗，最后说明提示词与 A22 推理工具的关系。演示时应使用自己的测试内容，避免展示私人聊天和 API Key。
