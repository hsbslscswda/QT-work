心晴 v5.1

这是《高级语言编程实训2》课程项目的 Qt/C++ 桌面应用。

1. 将压缩包全部解压到一个文件夹，不要只拿出 exe。
2. 双击 Xinqing.exe。安装包已包含 Qt 运行依赖。
3. 打开侧边栏底部“服务连接配置”，填写 API 地址、模型名与自己的 Key。
4. 保存后发送一条消息。使用 API 无需在本机下载模型或安装显卡推理环境。

模型权重、API Key 和调用额度不包含在安装包中。仅打开界面不需要连接模型。
本地模型部署及 A22 批量推理说明在源码仓库的 docs 目录。

聊天记录会保存在当前 Windows 用户的应用数据目录，设置中的 Key 为本机明文保存。
在共享电脑上使用时，请自行管理聊天记录和密钥。

Qt 许可与来源见 THIRD_PARTY_NOTICES.md 和 licenses/Qt。
